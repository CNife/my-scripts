# 中金换股套利计算器

**目录**: arbitrage_calculator/
**功能**: 计算中金公司吸收合并东兴/信达证券的换股套利空间
**技术栈**: Python

## 概述

计算中金换股吸收合并东兴/信达证券的套利收益，包括正向换股套利和现金选择权套利两种策略。

## 文件结构
```
arbitrage_calculator/
└── arbitrage_calculator.py       # 套利计算主脚本
```

## 核心功能

### 套利策略
| 策略 | 说明 | 适用场景 |
|------|------|----------|
| 正向换股套利 | 买入被合并方股票，换股后卖出中金 | 收益 > 3% 具备实操价值 |
| 现金选择权套利 | 买入被合并方股票，行使现金选择权 | 收益 > 0 有保底收益 |

### 固定参数
| 证券 | 换股比例 | 现金选择权价格 |
|------|----------|----------------|
| 东兴证券 | 0.4373 | 13.13 元 |
| 信达证券 | 0.5188 | 17.79 元 |

## 使用方式

```bash
uv run python arbitrage_calculator/arbitrage_calculator.py
```

运行后交互式输入：
1. 中金公司当前股价
2. 东兴证券当前股价
3. 信达证券当前股价

### 输出示例
```
===== 套利空间计算结果 =====
【东兴证券】
正向换股套利收益：5.23%
现金选择权套利收益：2.15%

【信达证券】
正向换股套利收益：3.87%
现金选择权套利收益：1.52%
```

## 注意事项

1. **输入格式**: 股价需输入数字格式（如 34.20）
2. **结果解读**:
   - 正向套利收益 > 3% 具备实操价值
   - 现金选择权套利需满足投反对票 + 持续持股条件
3. **优先策略**: 正向换股套利收益通常更高，优先选择
