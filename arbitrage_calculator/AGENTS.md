# 中金换股套利计算器

**技术栈**: Python（交互式）

## 文件结构
```
arbitrage_calculator/
└── arbitrage_calculator.py
```

## 使用
```bash
uv run python arbitrage_calculator/arbitrage_calculator.py
# 交互式输入：中金股价、东兴股价、信达股价
```

## 套利策略
| 策略 | 说明 |
|------|------|
| 正向换股套利 | 买入被合并方 → 换股 → 卖出中金 |
| 现金选择权套利 | 买入被合并方 → 行使现金选择权 |

## 固定参数（2026-05-18 公告报告书草案）
| 证券 | 换股比例 | 换股价格 | 现金选择权 |
|------|----------|----------|------------|
| 东兴证券 | 0.4376 | 16.05 元 | 13.13 元 |
| 信达证券 | 0.5210 | 19.11 元 | 17.79 元 |
| 中金公司 | — | 36.68 元 | — |

## 注意事项
- 正向套利收益 > 3% 具实操价值
- 现金选择权套利需投反对票 + 持续持股
- 换股平价（公允价值）= 中金股价 × 换股比例，市价低于平价时加仓可降低等效中金成本
